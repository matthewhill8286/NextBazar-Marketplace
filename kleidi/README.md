# Kleidi

Cyprus property **closing file** — one plot, one checklist, one vault. Not a classifieds site.

Weekend demo: Vite + React, state in `localStorage`. No Stripe, no accounts.

```bash
npm install
npm run dev
```

[http://localhost:4900](http://localhost:4900)

- Sample file: Peyia / Cap St. George, off-plan, trapped title
- EN / EL, buyer / lawyer view
- Click a checklist row to cycle status

Postgres sketch: `schema.sql`. Domain types: `types.ts`.
